# 建模实现说明与取舍（Implementation Notes）

> 配套 [`research.md`](research.md)（考据依据）与 [`engine-api.md`](engine-api.md)（引擎/协作契约）。
> 本文记录最终交付模型相对考据的**实现参数、尺度与有意取舍**，供复核与后续完善。

## 一、尺度与坐标

- 世界：`320 × 96 × 320` 体素，坐标 `x 东(+)/西(-)`、`z 南(+)/北(-)`、`y 上`；园心为原点，园墙 `x,z = ±148`。
- **1 体素 ≈ 1 米**。相对考据建议的 0.5 m/体素做了 1:1 粗化：voxel 体素风格需要更粗的颗粒才能在总览里读出形体；单件建筑按清式尺度归纳（明间 4、次间 3.5–4 格；檐高 3–6；脊高 6–22）。
- 园内可用面积约 296×296 格（≈8.8 ha），较考据折算的 340×400 m 略小且取方形；拓扑（中轴、四院、水系、山体关系）严格保留。
- 单位高程序：普通地面顶层实体 `y=3`（可行走面 4）；水面 `y=3.35`；台地见 `layout.ELEV`/`PADS`。

## 二、总平面要点（与考据的对应）

| 考据结论 | 实现位置 |
|---|---|
| 中轴不弯：正门—翠嶂—沁芳亭—牌坊—正殿—大观楼 | x=0，z 由 +146 至 −140 |
| 潇湘馆西南、怡红院东南、稻香村西北、蘅芜苑北偏东 | (−100,42) / (58,32) / (−110,−80) / (40,−104) |
| 沁芳溪单线连通：沁芳闸→东北山坳→花溆→沁芳池→沁芳亭→东南出水 | 由 `layout.PONDS/STREAMS` 生成的连续水面，东南角出水口 |
| 大主山分脉、花溆云步石梯、翠嶂障景 | `terrain.HILLS` + 蘅芜苑台地/花溆石阶/翠嶂石洞 |
| 栊翠庵山环红梅、凸碧山庄/凹晶溪馆一山一水 | (96,−128) / (118,−96) / (90,−82) |
| 藕香榭池中、紫菱洲·缀锦楼、荇叶渚、滴翠亭 | 池中洲渚，见 `layout.ZONES` |

## 三、主要取舍

1. **桥梁位置微调**：考据锚点多落在开阔湖心，无法两端落地；由各场景负责人在邻近真实岸线重建（蜂腰桥 → (−72,−45)；紫菱洲九曲桥中心 (2,−9)；荇叶渚折桥中心 (−30,−9)；藕香榭两段竹桥、木桥等见 `layout.BRIDGES` 注释）。
2. **建筑形制**：官式（正殿、大观楼、牌坊）用金/绿琉璃、歇山/重檐；民居院落用灰瓦、硬山/卷棚/攒尖，均以体素分层退台 + 瓦垄 + 飞檐 + 檐下彩画带表达。部分院落由场景作者自写屋面（与 helpers 屋面同语言），以保留各自细节。
3. **匾额楹联**：以 CanvasTexture 贴片悬于原位（非体素），保证中文可读；同时保留初题/元春改题对照（见信息卡）。
4. **植被**：以「绿荫为主、花树按景点集中」为原则；潇湘馆竹、稻香村杏、栊翠庵红梅、沁芳闸桃、花溆桃杏、怡红院海棠、红香圃芍药、藕香榭桂荷等均按考据配置；水面只种荷/苇。
5. **地形微起伏**：为打破平板草地，在院外空地加入 0–1 格随机起伏；台地/院落/道路保持平整。
6. **水色**：取青绿偏蓝的园林水色；昼/晨/暮/夜四套调色，夜间灯笼、窗纸自发光。
7. **性能**：贪心网格化 + 烘焙 AO/日照阴影，无实时阴影贴图；单次绘制约 28 万合并面（≈59 万三角面）、约 120 draw call；移动端自动降像素比与画质并动态分辨率。

## 四、与考据的已知差距（可继续完善）

- 园界取方形、略小于「三里半」折算值；若需严格比例，可整体放大平面（拓扑不变）。
- 部分小景（芭蕉坞、蔷薇院、荼蘼架、木香棚、牡丹亭）以意象化小体量呈现，未做完整院落。
- 室内陈设仅以体素意象（屏风、条案、镜屏、大案）示意，无家具细部。
- 匾联部分采用繁体以保持原书题额面貌；正文考据与信息卡用简体。
- 各院花木数量、树种为考据+观感平衡，非植物学清单。

## 五、Phase 2 · 高精细升级（HD）

> 第二版在保留原总平面、体素基底与全部景点内容的前提下，用「程序化材质 + 精细构件网格 + 实例化植被 + 动态水 + 第一人称步行」四层叠加，解决初版「大方块、植被呆板、水面静止、不能入内」的问题。

### 5.1 体素材质着色器（`src/core/renderer.js`）

- 体素网格在 mester 阶段写入 `aMat`（材质类：草地/铺地/粉墙/瓦面/木/石/金属/河床/植物/织物/纸）与 `aFace`（面方向）两个顶点属性。
- 自定义 GLSL 在片元中按材质类程序化生成细节：**瓦垄 + 瓦排**、粉墙水渍、石材斑点/石缝、铺地石板缝、木纹/门钉、草地大尺度色斑 + 细草噪声；并按 0.10m 弱倒角（边缘压暗 + 微高光）处理**每一个体素**，使 1m 方格看上去像有厚度的砖石/木作，而不是平涂色块。
- 颜色仍保持原有「sRGB → linear 烘焙 + 顶点色」管线；自定义 shader 末尾手工转回 sRGB，与 UI/水面/植被的取色一致；雾/TOD tint 通过 uniform 同步。
- 移动端 `quality!=='high'` 时关闭大部分程序化纹理（`uDetail` 0.55/0），只保留倒角与色斑，控制片元开销。

### 5.2 精细建筑构件（`src/garden/ornaments.js`）

- helpers 在生成体素的同时把构件规格 push 到 `ctx.details`：`roofs / columns / lattices / railings / doors / furniture / lanterns / banners`。
- `buildDetails()` 生成 **≈95k tris、5 个 Mesh、4–5 draw call** 的精细构件：封檐板、瓦当、檐椽、飞檐角梁+套兽、正脊/脊筒/鸱吻、垂脊/走兽、卷棚博风板、攒尖宝顶；柱础+柱身+斗拱；四式门窗棂（步步锦/冰裂纹/回纹/直棂，含糊纸）；木/石/竹栏杆（望柱/扶手/栏板）；板门/隔扇门（含门钉/铺首、可开合、常开 68°）；18 类家具陈设（条案/太师椅/架子床/书架/三扇屏风/字画/香炉/烛台/地毯/帷幔/琴/茶具等）；红灯笼（夜间暖光）与题字幡/匾。
- 大尺度屋面自动降细节（跨度 >26m 保守模式、>34m 仅封檐板+瓦当+正脊），避免“细杆天线”；坐标越界/非法 spec 直接跳过并记录，保证无 NaN 顶点。
- helpers 中**柱、栏杆、窗棂、门扇的体素被隐藏/清空**，由精细网格替换；体素碰撞仍然保留（门格按开合状态放行）。

### 5.3 实例化植被与风摆（`src/garden/flora.js` + `src/garden/foliage.js`）

- 彻底移除 1m 体素树冠；叶片为**实例化叶片卡**（程序化 20 格图集、内联 CanvasTexture），共享风摆 shader：按相位/幅度、直立/下垂/整卡权重与空间波做位移，柳条大摆、竹叶簌簌、荷/荇轻浮、草花细颤；树木另有低模枝干与「冠核」（半径硬上限 2.4m）保证中远景是明确的绿色团。
- 桌面：叶实例 117,916 / 草花 54,771，植被 **8 draw call**；移动端自动减半（叶 60k/草花 29k，单株卡量 ×0.56）。
- 品种：海棠/杏/桃/梨/梅的花云、松针层片、竹丛（竿+叶簇）、芭蕉大叶、垂柳长条、梧桐/银杏/榆/槐/桑冠形；水面荷/浮萍/荇/苇。POI 机位 8m 内不种树，避免镜头穿冠。

### 5.4 精细动态水系（`src/core/water.js` + `water-shader.js`）

- 流向场：由 `layout.STREAMS` 线段距离场加权 + `PONDS` 椭圆环流合成，逐格速度随河宽/汇流/跌水/池心变化，2 遍平滑 + 角点共享属性消除 1m 棋盘缝。
- 5 层方向波（主流/斜交/长波/汇流撕裂/细涟漪）+ 解析法线；BFS 离岸距离场驱动岸边泡沫，桥墩泡沫按 `layout.BRIDGES` 生成；四时水色/菲涅耳天空反射/太阳高光/浅深水色与透明度；沁芳闸、花溆石洞的白水帘并入同一几何（不增 draw call）+ GPU 水花/水雾粒子；14 条锦鲤 InstancedMesh 绕池游动。
- 水系统 3 draw call（水/粒子/锦鲤），水面 11,010 quads / 22,020 tris。

### 5.5 第一人称步行与可入内（`src/core/walker.js` + `src/ui/walk.js`）

- 眼高 1.65m、碰撞 AABB 0.34m、重力与自动上台阶（≤2.4m，可上月台/汀步）、水域阻挡（桥面/石矶可过）、室内自动识别的暖色提亮（canvas CSS filter，退出即复原）。
- 门：H.door 隐藏门扇体素 + 精细可开合门；门格按 `open>0.55` 放行；按 `E` 可开关，靠近时 HUD 显示提示。
- 桌面：WASD/Shift/Space/E/V/Esc；移动端：左下摇杆 + 右侧疾跑/跳跃/退出，画布拖拽转身；POI 目录/小地图点击传送（`layout.POIS[].walk` 为每个景点配置了步行落点）。
- 室内：H.hall 自动陈设 + `H.furnish` 按厅/书房/卧室/宴席风格布置；怡红院、秋爽斋、暖香坞、滴翠亭、正殿、大观楼、潇湘馆、稻香村、芦雪庵、红香圃、栊翠庵、凹晶溪馆、藕香榭、缀锦楼等均可进入观赏。

### 5.6 建筑增高与比例

- 正门墙高 4→6；正殿檐 5/柱 6→7/9，屋顶加高；大观楼两层柱 5/5、腰檐/平座/二层整体抬升，脊高约 +20%；东/西/北/水区主体建筑由场景负责人按 1.2–1.5× 抬高（详见各场景注释），并同步抬升柱/墙/门窗/匾联/台阶/栏杆，保证衔接。

### 5.7 性能（桌面 high / 移动 mid）

| 指标 | 桌面 high | 移动 mid |
|---|---|---|
| tris | ≈1.12M | ≈0.73M |
| draw calls | ≈150 | ≈96 |
| 体素 solidQuads | ≈137k | ≈137k |
| 植被实例 | 117,916 叶 + 54,771 草花 | 减半 |
| 水面 | 11,010 quads + 粒子/锦鲤 | 减半粒子 |
| 构建 | ≈2–5s（随机器负载波动） | ≈3–8s |

> 说明：本项目仍是「1m 体素」为骨、细网格/实例化为皮的混合风格；若需真正 0.5m 体素级分辨率，需要重建总平面与全部场景（工作量等同重做），本次未采用。
